# Activating Eternl Pro [[ProButton]](/welcome-to-eternl-v2/eternl-pro.md)

This guide explains the steps to check, purchase, and activate Eternl Pro. For an overview of Eternl Pro, its purpose, and its features, see [Eternl Pro](/welcome-to-eternl-v2/eternl-pro.md).

## Check Pro Access {open}

To check whether an account already has access to Eternl Pro:

1. Open the **Pro plan** window.
2. Optionally select the **Individual Yearly** or **Business Yearly** plan before checking access.
3. Select the account to use as the **License Account**.
4. Click **Check Pro Access**.
5. Confirm the selected account in the signing dialog. You can select a different account there if needed.
6. Sign the wallet proof.

:::info
The wallet proof confirms that you control the selected License Account. It does **not** initiate a purchase, make a payment, or move funds.

If you purchase a new license, the later on-chain activation requires a network fee. Make sure the License Account has enough ADA to cover it.
:::

The License Account must be able to sign the wallet proof. Read-only and multi-sig accounts cannot be used for this step.

If an active license is found, Eternl guides you through activating it on the current device. If no existing access is found, and you selected a plan beforehand, Eternl continues directly to checkout. Otherwise, choose a plan first.

:::tip
A Pro license is linked to one License Account, but its features are available for all wallets and accounts in the same entity.
:::

## Purchase and Activate Pro

Dodo Payments checkout opens in a new tab.

Available payment methods are shown in the Dodo Payments checkout. At the time of writing, these include card payments, Apple Pay, Google Pay, Amazon Pay, WeChat, and stablecoins. The available options can vary by location and provider checks, while the information required during checkout can depend on the selected payment method.

Before payment, review the plan, yearly term, price and taxes, payment method, and any information requested by Dodo Payments.

Once payment is confirmed, return to Eternl and follow the remaining prompts. You will be asked to sign and submit a Cardano license activation transaction, which requires network fees. Finally, sign the device proof to unlock Pro on the current installation.

## Activate Existing Pro

If you already purchased Pro for the selected License Account, use **Check Pro Access** and sign the wallet proof. Eternl then guides you through the device activation steps required for the current installation.
