# Set Up Eternl and Create a Wallet

{% embed url="https://www.youtube.com/watch?v=T6AHdtmmWwg" %}

This guide covers the initial setup of Eternl and how to create a new wallet. If you already have a wallet, you can instead [add your existing wallet](/using-eternl/getting-started-with-eternl/add-an-existing-wallet.md) after setting up Eternl.

Eternl is a non-custodial wallet. You are responsible for keeping your wallets and seed phrases secure. A seed phrase, also called a recovery phrase, is the master key to a wallet: it can be used to restore the wallet and control its funds.

For more information, see [What Is a Seed Phrase?](/crypto-and-cardano-basics/security-and-privacy/what-is-a-seed-phrase.md) and [Security Best Practices](/crypto-and-cardano-basics/security-and-privacy/Security-Best-Practices.md).

## Set Up Eternl

1. Open [eternl.io](https://eternl.io) in your browser, or install and open the Eternl browser extension or the Eternl app for iOS or Android. Click **Start setup**.
2. Review the available settings, such as language, currency, and network. Adjust them if needed, then click **Next**.
3. Set a PIN code to protect access to this Eternl installation, or click **Skip** to continue without one. The PIN is only a local access protection and is separate from your wallet's spending password.
4. Read and accept the Terms of Service and Privacy Policy to continue.

After setup, Eternl opens the wallet selection screen. You can create a new wallet or add an existing one.

## Create a New Wallet

:::warning
Your seed phrase gives access to your wallet and funds. Never share it with anyone, and store it securely offline. Eternl cannot recover it for you.
:::

:::warning
Your spending password is used to authorize actions in Eternl (if you don't use a hardware wallet), while the seed phrase can be used to restore your wallet or reset the spending password. Keep both secure.
:::

1. Select **New Wallet**. If you have already closed the wallet selection screen, click **Add wallet** at the bottom of the wallet list first.
2. Click **Show recovery phrase** and write down all words in the displayed order. Keep it in a secure, offline location.
3. Confirm the seed phrase by selecting the requested words.
4. Choose how many accounts to create. One account is selected by default, and you can add more accounts later.
5. Enter a name for your wallet.
6. Set a strong spending password and click **Create**.

:::warning
For larger holdings, consider using a hardware wallet. It keeps your private keys on a separate device and provides additional protection compared with a software wallet. You still need to keep its seed phrase secure.
:::
