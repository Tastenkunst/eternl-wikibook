# Media

The **Media** section provides a dedicated library for supported audio and video NFTs across your Eternl wallets. It lets you search, filter, sort, and play media without having to find each item in the asset list.

![Media](/assets/pictures/media.jpg)

## Browse Media

The page shows the total number of media items found across all wallets. Use the category filters to switch between:

* **All**: Shows all supported media items.
* **Music**: Shows audio items.
* **Video**: Shows video items.

Use the search field to search by title, artist, description, policy, or fingerprint. The media list shows information such as the title, collection, media type, and time. Use the column headings to sort the list where sorting is available.

Click a media item to open it in the player. **Play all** starts playback of the listed media items and adds them to the playback queue.

## Media Player

The player provides the usual playback controls for the selected media. Eternl also supports a playback queue, shuffle, and repeat controls. The player remains available while you continue using Eternl, so you can keep listening while navigating to another section of the app.

## Media Settings

Click the **gear icon** on the Media page to open the Media settings. For details about offline storage, IPFS gateways, missing durations, and rescanning wallets, see [Media Settings](/using-eternl/settings/app-settings.md#media).
