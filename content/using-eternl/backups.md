# Backing Up and Restoring Eternl

Eternl can export a backup file so that you can restore your wallets and selected local data if you move to another Eternl installation or lose your browser data. You can back up a single wallet or export a broader selection of data from the app.

:::warning
Backup files can contain sensitive wallet information. Store them securely, do not share them, and keep any password used to protect them safe. A backup file does not replace a secure copy of your recovery phrase.
:::

## Back Up Your Wallets and App Data

Use **Export Data** to create a backup containing the data categories you select, such as wallets, application settings, address book entries, and transaction notes.

1. Open **Settings > App Settings > Export Data**.
2. Select the data you want to include. Make sure **Wallets** is selected if you want to back up your wallets.
3. Enter and confirm a password for the backup. You will need this password when importing the file.
4. Click **Download Backup** and save the file in a secure location.

The backup contains the data selected when it was created. Create a new backup after making changes you want to preserve.

## Restore App Data From a Backup

1. Open **Settings > App Settings > Import Data**.
2. Select your backup file.
3. Enter the backup password when prompted.
4. Review the available data and select what you want to import. If Eternl asks how to handle existing data, review the options before continuing.
5. Confirm the import and check the result.

## Back Up a Single Wallet

1. Select the wallet you want to back up.
2. Open **Settings > Wallet Settings > Export Wallet**.
3. Enable **Password Protection** and set a password to encrypt the exported file.
4. Click **Export Wallet** to save the file.

If password protection is disabled, the exported file is not encrypted with an additional backup password. Store it securely in either case.

## Import a Wallet Backup

1. Click **Add wallet** at the bottom of the wallet list.
2. Select **More**, then **Import Backup**.
3. Select the backup file and follow the instructions in Eternl. If the backup is password protected, enter the password when prompted.

For more ways to add a wallet, see [Add an Existing Wallet](/using-eternl/getting-started-with-eternl/add-an-existing-wallet.md).
