# Eternl Hub [[ProButton]](welcome-to-eternl-v2/eternl-pro.md)

The **Eternl Hub** is a secure connection layer that allows you to pair multiple Eternl instances across devices, perform remote transaction signing, and connect dApps without sharing private keys or recovery phrases.

::: info
Full Eternl Hub functionality is available for **[Eternl Pro](welcome-to-eternl-v2/eternl-pro.md)** users.
:::

## General {open}

### What Is Eternl Hub?

Eternl Hub simplifies multi-device management and transaction authorization. Instead of entering seed phrases or importing backup files on multiple devices, you can pair a primary instance (such as a hardware-wallet-connected browser extension) with a secondary instance (like Eternl PWA on mobile or a secondary PC).

This enables seamless **remote signing**, temporary wallet sharing, and cross-device dApp interactions.

---

### Key Advantages & Use Cases

* **Remote Signing:** Initiate a transaction on a secondary device (e.g., mobile) and sign it securely on your primary device or hardware wallet without moving keys.
* **Seedless Multi-Device Access:** Share read/spend access with other devices without exporting JSON backups.
* **Temporary & Permanent Sharing Modes** [[ProButton]](welcome-to-eternl-v2/eternl-pro.md): Choose whether shared wallets remain temporarily synced or are permanently added to the paired device.
* **Centralized dApp Remote Connection:** Connect dApps on one device while processing transactions securely through another paired Eternl instance.

---

## Access & Status Indicator

### Opening Eternl Hub

You can open the Eternl Hub modal using two quick methods:

1. **Header Status Icon (Lightning Bolt):** Click the **green lightning bolt icon** in the top navigation bar, then select **Manage Connections** (or click directly on **Paired Devices** / **Connected DApps**).
2. **Settings Menu:** Navigate to **Three-dot menu > Settings > App Settings > Eternl Hub**.

### Header Status Indicator

The **lightning bolt icon** in the header shows real-time Hub status:
* **Green Icon with Number Badge:** Indicates active connections and shows the count of currently paired devices or connected dApps online.
* **Quick Stats Dropdown:** Hovering or clicking the icon opens a quick summary of online paired devices and connected dApps.

### Disabling Eternl Hub Completely

If you do not use multi-device features and prefer to turn off background Hub connections:
1. Go to **Settings > App Settings > Eternl Hub** (or open the **Join** / **Connections** tab inside the Hub modal).
2. Toggle the **Eternl Hub** switch **OFF**.

:::info
Disabling Eternl Hub completely hides the lightning bolt status icon from the top navigation bar. You can re-enable it anytime from **App Settings**.
:::

## Pair Wallet

The **Pair Wallet** tab generates a short-lived 6-digit pairing code and QR code to pair your current Eternl instance with another device.

* **Code & QR Expiry:** Codes refresh every 30 seconds for security.
* **Wallets to Share:** Select specific wallets and accounts you want to make available on the paired device.
* **Sharing Mode Toggle [[ProButton]](welcome-to-eternl-v2/eternl-pro.md):**
    * **Temporary Mode (Switch OFF):** Shared accounts are available as temporary wallets. Paired devices cannot export them, and revoking sharing automatically removes the wallets from the paired device.
    * **Full Sync Mode (Switch ON):** Wallets will persist on the paired device even if you revoke sharing. This action cannot be undone remotely.

---

## Connect DApp

The **Connect DApp** tab allows you to link dApps via Remote Connect codes while bypassing single-account restrictions.

* **Multi-Account Selection:** Select multiple accounts across different wallets to expose them simultaneously to the connected dApp.
* **Remote Connection Code:** Enter the generated code in the dApp interface to establish the secure connection without needing a local wallet extension on that specific browser.

---

## Join

Use the **Join** tab on a receiving device to enter a 6-digit pairing code or scan a QR code generated by another Eternl instance or dApp.

* Enter the code shown on the primary device and click **Connect Instance**.
* Toggle **Eternl Hub** ON/OFF at the bottom to globally enable or disable device pairing and remote multi-device signing on this instance.

---

## Connections

The **Connections** tab provides an overview of all active pairings and linked dApps.

* **Paired Instances:** View and manage all paired Eternl devices active for wallet sync and remote signing. You can revoke access for any paired instance at any time.
* **Connected DApps:** Monitor and disconnect active dApps linked via Remote Connect codes.
